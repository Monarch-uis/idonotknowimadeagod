Quick Start Guide
=================

Get up and running in 5 minutes!

Basic Workflow
--------------

.. code-block:: text

   📚 EPUB → 🎤 TTS → 🎬 Video → ✨ Output

Step 1: Place Your EPUB
------------------------

Copy your EPUB file to the input folder:

.. code-block:: bash

   cp your-book.epub _NEW_EPUBS_HERE/

Step 2: Run the Converter
--------------------------

**Option A: Interactive Mode**

.. code-block:: bash

   python epub_project_manager.py

Follow the on-screen prompts to convert your EPUB!

**Option B: With Profiling**

.. code-block:: bash

   python run.py --profile

**Option C: Using Makefile**

.. code-block:: bash

   make run
