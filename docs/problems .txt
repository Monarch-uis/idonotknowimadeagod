### **2. Subtitle Timing Desynchronization**
**Severity:** 🔴 **CRITICAL** - Subtitles don't match audio  
**File:** `core/subtitle_generator.py`

**Problem:**
```python
def generate_chapter_subtitles(
    self, 
    chapter_text: str, 
    start_time: float, 
    chapter_duration: float
) -> List[Tuple[float, float, str]]:
    # ... splits text into chunks
    
    for chunk in chunks:
        # ❌ BUG: Uses ESTIMATED reading time instead of ACTUAL audio
        reading_time = self.estimate_reading_time(chunk)

        # This will NEVER match actual TTS audio!
```

**Why This Is Wrong:**
1. TTS engines speak at variable speeds (pauses, emphasis, etc.)
2. Estimation is just `word_count / 2.5` - completely inaccurate
3. No connection to actual audio timestamps
4. Subtitles will drift more and more as video progresses

**Impact:**
- Subtitles appear too early or too late
- Gets progressively worse throughout video
- Completely breaks for long content

**Proper Fix:**
```python
# Option 1: Use actual audio file duration (Best)
from pydub import AudioFile
audio_duration = AudioFile.from_file(audio_path).duration_seconds

# Option 2: Use faster-whisper timestamps (Most accurate)
# The video_pipeline.py already generates word-level timestamps!
# Use those instead of estimating
```

### **3. Index Error in Subtitle Chunking**
**Severity:** 🔴 **HIGH** - Can crash subtitle generation  
**File:** `core/subtitle_generator.py` line 56-60

**Problem:**
```python
sentences = re.split(r'([.!?]+\s+)', text)

for i in range(0, len(sentences), 2):
    sentence = sentences[i]
    separator = sentences[i + 1] if i + 1 < len(sentences) else ""
```

**Example That Crashes:**
```python

sentences = ['Hello', '. ', 'World']  # Length 3 (odd!)
# i=0: sentence='Hello', separator='. ' ✅

```

**Fix:**
```python
for i in range(0, len(sentences), 2):
    sentence = sentences[i]
    separator = sentences[i + 1] if i + 1 < len(sentences) else ""
    # Actually this IS safe because the condition checks!
    # But clearer to do:
    if i + 1 < len(sentences):
        full_sentence = sentence + sentences[i + 1]
    else:
        full_sentence = sentence
```

- Can fill disk after many renders
- Hard to track down leaked files

**Fix:**
```python
import tempfile
from contextlib import contextmanager

@contextmanager
def temp_ass_file(captions, config):
    """Context manager for temporary ASS file"""
    tmp_fd, tmp_path = tempfile.mkstemp(suffix=".ass")
    try:
        os.close(tmp_fd)
        # Write file...
        yield Path(tmp_path)
    finally:
        try:
            Path(tmp_path).unlink(missing_ok=True)
        except:
            pass

# Usage:
with temp_ass_file(captions, config) as ass_path:
    # Use ass_path...
    # Automatically cleaned up even on crash
```

### **7. Sanitize Filename Incomplete**
**Severity:** 🟡 **MEDIUM** - Breaks on special characters  
**File:** `core/utils.py` line 67

**Problem:**
```python
def sanitize_filename(name):
    """Clean filename for cross-platform compatibility"""
    valid_chars = "-_.() %s%s" % (string.ascii_letters, string.digits)
    cleaned = ''.join(c for c in name if c in valid_chars)
    return cleaned[:60].strip()
    # ❌ Problems:
    # 1. Removes Unicode (breaks for Chinese/Japanese titles)
    # 2. No path separator handling
    # 3. Can return empty string
    # 4. Doesn't handle reserved Windows names (CON, PRN, etc.)
```

**Real-World Failures:**
```python
# Japanese light novel title
sanitize_filename("転生したらスライムだった件")
# Returns: "" (empty!) ❌

# Path injection
sanitize_filename("../../etc/passwd")
# Returns: "..etcpasswd" ❌ (should reject!)

# Windows reserved name
sanitize_filename("CON.txt")
# Returns: "CON.txt" ❌ (will crash on Windows!)
```

**Proper Fix:**
```python
import re
import unicodedata

def sanitize_filename(name, max_length=200):
    """Properly sanitize filename for all platforms"""
    if not name:
        return "untitled"
    
    # Normalize Unicode
    name = unicodedata.normalize('NFKD', name)
    
    # Remove path separators
    name = name.replace('/', '_').replace('\\', '_')
    
    # Remove control characters
    name = ''.join(c for c in name if not unicodedata.category(c).startswith('C'))
    
    # Replace problematic characters
    name = re.sub(r'[<>:"|?*]', '_', name)
    
    # Handle Windows reserved names
    reserved = {'CON', 'PRN', 'AUX', 'NUL', 'COM1', 'COM2', 'COM3', 'COM4',
                'COM5', 'COM6', 'COM7', 'COM8', 'COM9', 'LPT1', 'LPT2',
                'LPT3', 'LPT4', 'LPT5', 'LPT6', 'LPT7', 'LPT8', 'LPT9'}
    if name.upper().split('.')[0] in reserved:
        name = f"_{name}"
    
    # Remove leading/trailing spaces and dots
    name = name.strip('. ')
    
    # Truncate while keeping extension
    if len(name) > max_length:
        parts = name.rsplit('.', 1)
        if len(parts) == 2:
            name_part, ext = parts
            name = name_part[:max_length - len(ext) - 1] + '.' + ext
        else:
            name = name[:max_length]
    
    return name or "untitled"
```

**Example Failure:**
```python
text = "fucking motherfucker"
banned = [r"\bfuck\w*", r"\bmotherfucker\w*"]

# Pattern 1 matches: "fucking", "fucker" (part of motherfucker)
# Pattern 2 matches: "motherfucker"
# Processing in reverse causes indices to be wrong!

# Result might be: "f**king motherf**ker" ❌
# Should be: "f**king m**ker" ✅
```

**Fix:**
```python
def censor_text_for_subtitles(text, banned_words):
    """Censor with proper handling of overlapping patterns"""
    if not text:
        return ""
    
    # Find ALL matches first with positions
    all_matches = []
    for pattern in banned_words:
        try:
            for match in re.finditer(pattern, text, flags=re.IGNORECASE):
                all_matches.append((match.start(), match.end(), match.group(0)))
        except re.error:
            pass
    
    # Sort by position (longest first for overlaps)
    all_matches.sort(key=lambda x: (x[0], -(x[1] - x[0])))
    
    # Remove overlapping matches (keep longest)
    filtered = []
    for start, end, word in all_matches:
        # Check if overlaps with any already added
        overlaps = any(s < end and e > start for s, e, _ in filtered)
        if not overlaps:
            filtered.append((start, end, word))
    
    # Sort by position (for replacement)
    filtered.sort(reverse=True)  # Reverse so indices stay valid
    
    # Replace
    result = list(text)
    for start, end, word in filtered:
        censored = partial_censor_word(word)
        result[start:end] = censored
    
    return ''.join(result)
```

```python
def validate_epub(epub_path):
    """Validate EPUB file before processing"""
    try:
        book = epub.read_epub(epub_path)
        
        # Check for required files
        if not book.get_metadata('DC', 'title'):
            return False, "Missing title metadata"
```

**Severity:** 🟡 **MEDIUM** - May reprocess chapters

**Problem:**
```python
def check_history_conflict(book_title, new_start, new_end):

        old_end = int(entry.get("end", 0))

        overlap_end = min(new_end, old_end)

            # Allows 1 chapter overlap
            # ❌ But what if user processes Ch 1-10, then 10-20?
            # Chapter 10 is DUPLICATED but not flagged!
```

**Better Algorithm:**
```python
def check_history_conflict(book_title, new_start, new_end):
    """Check for conflicts with improved logic"""
    history = load_history()
    key = sanitize_filename(book_title)
    if key not in history:
        return False, None
    
    conflicts = []
    
    for entry in history[key]:
        old_start = int(entry.get("start", 0))
        old_end = int(entry.get("end", 0))
        
        # Strict overlap check (no tolerance)
        if not (new_end < old_start or new_start > old_end):
            overlap_start = max(new_start, old_start)
            overlap_end = min(new_end, old_end)
            overlap_chapters = list(range(overlap_start, overlap_end + 1))
            
            conflicts.append({
                'range': f"Ch {old_start}-{old_end}",
                'date': entry.get('date', 'unknown'),
                'overlapping_chapters': overlap_chapters
            })
    
    if conflicts:
        return True, conflicts
    return False, None
```

### **12. No Audio Validation**
**Severity:** 🟠 **LOW** - Bad audio not detected  
**File:** All TTS functions

**Problem:**
```python
# After generating audio:
if os.path.exists(filename) and os.path.getsize(filename) > 1000:
    return True
# ❌ File exists and is >1KB, but is it VALID audio?
# Could be corrupted, silent, or wrong format
```

**Better Validation:**
```python
def validate_audio_file(filepath, min_duration=0.5):
    """Validate audio file is actually playable"""
    try:
        from pydub import AudioSegment
        
        audio = AudioSegment.from_file(filepath)
        
        # Check duration
        if audio.duration_seconds < min_duration:
            return False, "Too short"
        
        # Check if silent
        if audio.dBFS < -50:  # Very quiet
            return False, "Audio too quiet"
        
        # Check file size relative to duration
        size_mb = os.path.getsize(filepath) / (1024 * 1024)
        expected_size = audio.duration_seconds * 0.02  # ~20KB/sec rough estimate
        if size_mb < expected_size * 0.1:
            return False, "File size too small for duration"
        
        return True, None
        
    except Exception as e:
        return False, str(e)
```
